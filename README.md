# sportlife-info-bot

Telegram-бот для підписки на оновлення стану клубів (💡 світло, 🔥 гаряча / 🚰 холодна вода, 🏊 басейн, 🧖 лазні).
Дані беруться з опублікованої Google-таблиці (CSV). Бот періодично перевіряє таблицю і надсилає підписникам повідомлення, коли щось змінюється.

## Запуск

```bash
npm install
cp .env.example .env   # вкажіть BOT_TOKEN від @BotFather

npm run dev            # розробка (tsx, перезапуск при змінах)
# або
npm run build && npm start   # продакшн: компіляція в dist/ і запуск
```

Потрібен Node.js 22.13+ (використовується вбудований модуль `node:sqlite`, додаткових залежностей для БД не треба). Проєкт написаний на TypeScript (`strict`), `npm run typecheck` — перевірка типів.

`npm run check` — перевірити, що таблиця завантажується і коректно розбирається (без запуску бота).

## Можливості

- `/clubs` або «📍 Обрати клуби» — вибір міста й клубів (кнопки вмикають/вимикають підписку, є «Усі» / «Жодного» для міста)
- `/my` — список підписок з можливістю відписатися
- `/status` — поточний стан обраних клубів

## Налаштування (.env)

| Змінна | За замовчуванням | Опис |
|---|---|---|
| `BOT_TOKEN` | — | Токен бота (обов'язково) |
| `SHEET_URL` | посилання на таблицю | CSV-посилання на опубліковану таблицю |
| `POLL_INTERVAL_MINUTES` | `5` | Інтервал перевірки |
| `DB_FILE` | `data/bot.db` | Файл бази SQLite (підписки та останній стан клубів) |

## Структура

- `src/index.ts` — запуск, періодична перевірка, розсилка змін
- `src/bot.ts` — команди, меню та кнопки
- `src/sheet.ts` — завантаження/парсинг CSV, групування за містом, порівняння станів
- `src/storage.ts` — сховище на SQLite (таблиці `subscriptions`, `club_state`, `meta`)
- `src/format.ts` — форматування повідомлень
- `src/types.ts` — спільні типи
